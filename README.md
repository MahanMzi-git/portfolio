# Mahan Mizani — Portfolio

A dark, glassy personal portfolio website built from scratch with vanilla HTML and CSS. Showcases my projects, education, and background as a software engineering student.

🔗 **Live Demo:** [mahanmzi-git.github.io/portfolio](https://mahanmzi-git.github.io/portfolio/)

## ✨ Features

- **Hero section** — introduction, call-to-action buttons, and social links
- **Stats overview** — years studying, projects completed, technologies used
- **Projects showcase** — 4 featured projects with tech stacks and GitHub links
- **Education** — degree info and certifications (IBM, Udemy)
- **Contact form** — functional contact form powered by [Formspree](https://formspree.io), plus direct email/GitHub/LinkedIn links
- Fully responsive layout (desktop, tablet, mobile)

## 🛠 Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- [Formspree](https://formspree.io) for contact form handling
- Git & GitHub (feature branches + pull requests workflow)

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/MahanMzi-git/portfolio.git
   ```
2. Open `index.html` in your browser, or use the [VS Code Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension for live-reloading during development.
